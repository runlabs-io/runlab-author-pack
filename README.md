
# runlab author pack

This pack lets you build, develop, and test labs on your own machine. When a lab is ready, you publish it at runlabs.io.

Download the latest release and unpack it. The archive contains `trylab`, the program you run, plus what supports it: `prereqs`, `elevate`, `runlabctl`, a `packer/` directory of build scripts, and a short guide. Packer itself is not in the archive. `./prereqs` installs it, and installs `elevate`.

https://github.com/runlabs-io/runlab-author-pack/releases/latest

This repository holds only the releases. The pack is built from the private runlab repository.
