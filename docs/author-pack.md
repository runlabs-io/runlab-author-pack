# The author pack

[The author pack](https://github.com/runlabs-io/runlab-author-pack) runs a lab on your own computer, so you can change the lab and try it again as many times as you need, and publish it only when it's ready.

The lab machine is a Linux computer that runs inside your own, so your account has to be allowed to start it. The pack runs on a 64-bit PC with Linux. Because the installer uses apt, the package installer on Debian and Ubuntu, your computer should be running one of those.

The pack is a download, and the next page shows you how to install it. After that, the [Tutorial](tutorial/index.md) walks through the examples that come with it, and then you write a lab of your own.

The download also includes a short readme. This manual is where you learn the pack.
